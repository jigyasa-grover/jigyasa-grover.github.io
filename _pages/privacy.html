01 · Architecture & Data Minimization

Static hosting with no user accounts or tracking walls

This website (https://jigyasa-grover.github.io/) is published as a static Jekyll site hosted on GitHub Pages over HTTPS. It does not operate user logins, subscriber paywalls, third-party display ad networks, or data-broker pixels. All technical essays, open-source references, Markdown documents, and read-only JSON endpoints are publicly accessible without registration.

Standard infrastructure access logs (such as IP address, timestamp, and requested URL) are processed by GitHub Pages' CDN solely for security, DDoS protection, and reliable content delivery in accordance with the GitHub Privacy Statement.

02 · Aggregate Analytics & Browser Preferences

What cookies or local storage this site uses

  • Aggregate Traffic Analytics (Google Analytics 4): This site uses Google Analytics 4 (measurement ID G-GC9TNKJ6GT) to measure aggregate page views, article read depth, search topics, and outbound link clicks (such as booking storefronts and YouTube talks). No personally identifiable contact data is sent to analytics events. You can opt out at any time using your browser's tracking protections or the Google Analytics Opt-out Browser Add-on.
  • Light / Dark Reading Theme (localStorage): When you toggle the reading theme, a single local preference key (jg-theme) is stored in your browser so your visual preference persists across visits. It is never transmitted to a server.
  • Session Referrer Context (sessionStorage): A temporary per-tab session entry records whether a visit originated from an AI answer engine or search referral to understand aggregate readership sources. It clears automatically when you close the browser tab.
  • Embedded Videos (Click-to-Play): Embedded videos in the Screening Room use YouTube's privacy-enhanced mode (youtube-nocookie.com) and only load an iframe after you explicitly click play.
