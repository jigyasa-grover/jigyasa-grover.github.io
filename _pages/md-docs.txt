# Agent & Public Read-Only API Documentation

`jigyasa-grover.github.io` exposes free ($0 USD), unauthenticated, read-only JSON and Markdown endpoints over HTTPS so AI agents, research workflows, and developer tools can access verified structured data without scraping HTML.

## Authentication & Sandbox

- **Authentication:** None required (`security: []` in `/openapi.json`).
- **Free & Safe Sandbox:** All endpoints under `/api/v1/` are static, idempotent, read-only `GET` JSON resources safe for automated agent testing.
- **Base URL:** `https://jigyasa-grover.github.io`

## Public REST JSON Endpoints (`v1.0.0`)

| Endpoint | operationId | Description |
| --- | --- | --- |
| `GET /api/v1/index.json` | `getApiIndex` | API root index, version metadata, deprecation policy, and discovery links |
| `GET /api/v1/profile.json` | `getProfile` | Canonical `#person` profile, 50w/150w bios, career, education, awards, press photos |
| `GET /api/v1/collaboration.json` | `getCollaborationCatalog` | Collaboration pillars, Intro/Passionfroot/Naano/8x links, GTM packages, FAQs |
| `GET /api/v1/articles.json` | `listTechnicalArticles` | 34 indexed AI/ML/TPU articles with pagination metadata and Markdown twin URLs |
| `GET /api/v1/speaking.json` | `getSpeakingCatalog` | Google I/O keynote, signature talk abstracts, appearances, 21 countries |
| `GET /api/v1/publications.json` | `getPublications` | *Sculpting Data for ML*, Cornell Tech syllabus, 8 reviewed books, research papers |
| `GET /api/v1/projects.json` | `listProjects` | AI systems, GitHub stats, and upstream Hugging Face `peft` PR |
| `GET /api/v1/courses.json` | `getCoursesAndWorkshops` | LinkedIn Learning courses (~45K learners), live corporate workshops, clients |
| `GET /agent-context.json` | `getFullAgentContext` | Consolidated single-fetch agent context JSON |
| `GET /assets/data/cinema-catalog.json` | `getVideoCatalog` | 50+ developer films, talks, playlists, and 9:16 vertical Shorts |

## Example Requests

```bash
curl -s https://jigyasa-grover.github.io/openapi.json | jq .info
curl -s https://jigyasa-grover.github.io/api/v1/profile.json | jq '{name, current_role, short_bio_50}'
curl -s https://jigyasa-grover.github.io/api/v1/articles.json | jq '.pagination, .items[0]'
```

## Versioning & Error Recovery

Endpoints under `/api/v1/` follow Semantic Versioning (`1.0.0`). Any breaking contract change ships under `/api/v2/` with at least 90 days of parallel support. Missing resources return HTTP `404`; recover by inspecting `/openapi.json`, `/api/v1/index.json`, or `/llms.txt`.
