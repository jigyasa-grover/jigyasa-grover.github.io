> Hey folks 👋🏻 For those who missed the talk by [@AndrewYNg](https://twitter.com/AndrewYNg?ref_src=twsrc%5Etfw) on [#DataCentric](https://twitter.com/hashtag/DataCentric?src=hash&ref_src=twsrc%5Etfw) approach to [#MachineLearning](https://twitter.com/hashtag/MachineLearning?src=hash&ref_src=twsrc%5Etfw), which aligns with our mission [@DataForML](https://twitter.com/DataForML?ref_src=twsrc%5Etfw), here is a quick recap 🧵👇🏻— Sculpting Data: First Act of Machine Learning 📖 (@DataForML) [August 12, 2021](https://twitter.com/DataForML/status/1425685470730547206?ref_src=twsrc%5Etfw)

**AI = CODE + DATA** 🧠 So far, we have always focused on improving the code (i.e. making the model architecture more sophisticated) so much so that for most of the [#MachineLearning](https://twitter.com/hashtag/MachineLearning) problems today, we have easy access to open-source code.

**BETTER DATA = BETTER AI** 🔢 In this journey, data has been kept fixed and it has not received its due limelight. Hence, to make further progress in [#MachineLearning](https://twitter.com/hashtag/MachineLearning), we should now give importance to data (along with code/model) and adopt a [#DataCentric](https://twitter.com/hashtag/DataCentric) approach.

**SOPHISTICATED DATA ENGINEERING** 🛠 Data collection & labeling has been an intuitive process so far. Focus should now be to collectively evolve these processes & build relevant frameworks. This will eventually yield mature tools to streamline data collection & labeling workflow.

**ANALYSE DATA SLICES** 🍕 [#DataCentric](https://twitter.com/hashtag/DataCentric) paradigm modifies the [#ML](https://twitter.com/hashtag/ML) workflow. Here, after model training and performing error analysis, instead of improving the model architecture, we focus on finding a slice of data that needs attention to further improve model performance.

**PRIORITIZE DATA **🎖 Improvements in data should not be confused with data pre-processing. In fact, enhancements in data should continue even after the deployment and monitoring phase in the [#DataCentric](https://twitter.com/hashtag/DataCentric) paradigm.

**PRO TIP** 📖 [#DataCentric](https://twitter.com/hashtag/DataCentric) paradigm warrants learning how to build quality datasets to effectively solve [#MachineLearning](https://twitter.com/hashtag/MachineLearning) problems. Grab a copy of [@DataForML](https://twitter.com/DataForML) today and learn how to sculpt data the right way using [#Python](https://twitter.com/hashtag/Python) and other [#OpenSource](https://twitter.com/hashtag/OpenSource) tools!
