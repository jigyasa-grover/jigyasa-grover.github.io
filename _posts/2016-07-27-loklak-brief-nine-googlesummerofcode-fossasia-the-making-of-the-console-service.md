<p class="align-center margin">As <em>Google Summer of Code 2016</em> has officially begun, I am all excited to be working with <em>FOSSASIA</em> yet again. This time, I have been assigned the project <strong>Loklak</strong> where I shall be spending the summer working on implementing indexing (harvester/scrapers) for different services like <a href="http://www.weibo.com/">weibo.com</a>, <a href="https://angel.co/">angel.co</a>, <a href="http://www.meetup.co">meetup.com</a>, <a href="https://www.instagram.com">Instagram</a> etc.</p>
<p class="align-center margin"><a href="http://loklak.org/">Loklak</a> is a server application which is able to collect messages from various sources, including Twitter. This server contains a search index and a peer-to-peer index sharing interface.</p>
<p class="align-center margin">If one likes to be anonymous when searching things, want to archive Tweets or messages about specific topics and if you are looking for a tool to create statistics about Tweet topics, then Loklak is the best option to consider.</p>

<h2 class="entry-title"><span>The Making of the Console Service</span></h2>
<p><a href="http://asksusi.com/">SUSI</a> , our very own personal digital assistant has been up and running giving quirky answers.</p>
<p>But behind all these are rules which train our cute bot to assist her and decide what answers to provide after parsing the question asked by the users.</p>
<p>The questions could range from any formal-informal greetings, general queries about name, weather, date, time to specific ones like details about some random <em>Github</em> profile or <em>Tweets</em> and <em>Replies</em>  from Twitter, or Weibo or election/football score predictions or simply asking her to read a <em>RSS feed </em>or a <em>WordPress </em>blog for you.</p>
<p>The rules for her training are written after that specific service is implemented which shall help her fetch the particular website/social network in question and scrape data out of it to present it to her operator.</p>
<p>And to help us expand the scope and ability of this naive being, it shall be helpful if users could extend her rule set. For this, it is required to make console service for sites which do not provide access to information without <em>OAuth</em>.</p>
<p>To begin with, let us see how a console service can be made.</p>
<p>Starting with a <em>SampleService</em> class which shall basically include the rudimentary scraper or code fetching the data is defined in the package <em>org.loklak.api.search</em>.<br />
This is made by extending the <a href="http://loklak.github.io/loklak_server/org/loklak/server/AbstractAPIHandler.html"><em>AbstractAPIHandler</em> </a>class which itself extends the <em>javax.servlet.http.HttpServlet</em> class.<br />
<em>SampleService</em> class further implements <a href="http://loklak.github.io/loklak_server/org/loklak/server/APIHandler.html"><em>APIHandler</em></a> class.</p>
<p>A placeholder for <em>SampleService</em> class can be as:</p>
<pre><code>

<p>The <em>JSONArray</em> in the key function <em>crawlerForService</em> is wrapped up in a <em>SusiThought</em> which is nothing but a piece of data that can be remembered. The structure or the thought can be modeled as a table which may be created using the retrieval of information from elsewhere of the current argument.</p>
<p>Now to implement it as a<em> Console Service</em> we include it in the <em>ConsoleService</em> class which is defined in the same package <em>org.loklak.api.search</em> and similarly extends <a href="http://loklak.github.io/loklak_server/org/loklak/server/AbstractAPIHandler.html"><em>AbstractAPIHandler</em> </a>class and implements <a href="http://loklak.github.io/loklak_server/org/loklak/server/APIHandler.html"><em>APIHandler</em></a> class.</p>
<p>Here, <em>dbAccess </em>is a static variable of the type <em>SusiSkills</em> where a skill is defined as the ability to inspire, to create thoughts from perception. The data structure of a skill set is a mapping from perception patterns to lambda expressions which induce thoughts.</p>
<pre><code>
package org.loklak.api.search;

/**
 * <em><strong>import statements go here</strong></em>
**/

public class ConsoleService extends AbstractAPIHandler 
    implements APIHandler {

    private static final long serialVersionUID = 8578478303032749879L;
    /**
     * <em><strong>serialVersionUID could be 
     * auto-generated by the IDE used</strong></em>
    **/

    @Override
    public BaseUserRole getMinimalBaseUserRole() { 
        return BaseUserRole.ANONYMOUS; 
    }

    @Override
    public JSONObject getDefaultPermissions(BaseUserRole baseUserRole) {
        return null;
    }

    public String getAPIPath() {
        return "/api/console.json";
    }

    public final static SusiSkills dbAccess = new SusiSkills();
        static {

            /**
             * <em><strong>Other "skills" are defined here
             * by "putting" them in "dbAccess"</strong></em>
            **/
    
    dbAccess.put(Pattern.compile("SELECT\\h+?(.*?)\\h+?FROM\\h+?
        sampleservice\\h+?WHERE\\h+?url\\h??=\\h??'(.*?)'\\h??;"), 
            (flow, matcher) -&gt; {
                /**
                 * <em><strong>SusiThought-s are fetched from the Services
                 * implemented as above</strong></em>
                **/
                SusiThought json = SampleService.crawlerForService(matcher.group(2));
                SusiTransfer transfer = new SusiTransfer(matcher.group(1));
                json.setData(transfer.conclude(json.getData()));
                return json;
                });
    }

    @Override
    public JSONObject serviceImpl(Query post, HttpServletResponse response, 
        Authorization rights, final JSONObjectWithDefault permissions) 
        throws APIException {

            String q = post.get("q", "");
            /**
             *<em><strong>This would extract the argument that will be supplied
             * to the "q" parameter in the "post" query</strong></em>
            **/
            

            return dbAccess.inspire(q);
        }

}

</code></pre>
<p>Now that the console service is made, an API endpoint for the same can correspond to: <strong><a href="http://localhost:9000/api/console.json?q=SELECT" rel="nofollow">http://localhost:9000/api/console.json?q=SELECT</a> * FROM sampleservice WHERE url = &#8216; &#8230; &#8216;;</strong></p>
