<p class="align-center margin">As <em>Google Summer of Code 2016</em> has officially begun, I am all excited to be working with <em>FOSSASIA</em> yet again. This time, I have been assigned the project <strong>Loklak</strong> where I shall be spending the summer working on implementing indexing (harvester/scrapers) for different services like <a href="http://www.weibo.com/">weibo.com</a>, <a href="https://angel.co/">angel.co</a>, <a href="http://www.meetup.co">meetup.com</a>, <a href="https://www.instagram.com">Instagram</a> etc.</p>
<p class="align-center margin"><a href="http://loklak.org/">Loklak</a> is a server application which is able to collect messages from various sources, including Twitter. This server contains a search index and a peer-to-peer index sharing interface. If one likes to be anonymous when searching things, want to archive Tweets or messages about specific topics and if you are looking for a tool to create statistics about Tweet topics, then Loklak is the best option to consider.</p>
<p><img src="/assets/images/wp-archive/2016/loklak_anonymous-c0030999.png" alt="Illustration 2 — Loklak Brief: TWO GoogleSummerOfCode FOSSASIA  Loklak Weibo: Now going beyond Twitter" loading="lazy" /></p>
<hr />
<p><span><strong>Loklak Weibo: Now going beyond Twitter !</strong></span></p>
<p>As of now, <strong>Loklak </strong>has done a wonderful job in collecting billion(s) of tweets especially from Twitter. The highlight of this service has been anonymous search of Twitter without the use of any authentication key. The next step is to go beyond Twitter and collect data from <em>Chinese twitter</em> like services for instance <a href="http://weibo.com/">Weibo.com</a>.</p>
<p></p>
<p>The major challenge however is to understand the Chinese annotations especially being from a non-Chinese background, but now that I have support of a Chinese friend from the Loklak community,  we hope it shall be an easier task to achieve now 🙂</p>
<p>The trick shall be simple, to parse the HTML page of the search results. It has been suggested to use the <em>JSoup: The Java HTML parser library </em>in the <a href="https://github.com/loklak/loklak_server">loklak_server</a>. It provides a very convenient API for extracting and manipulating data, scrape and parse HTML from a URL. The suggested use of <em>JSoup</em> is designed to deal with all varieties of HTML, hence as of now it is being considered a suitable choice.</p>
<p>In our approach, the HTML page generated by the search query <span><em><a href="http://s.weibo.com/weibo/&lt;search-string&#038;gt" rel="nofollow">http://s.weibo.com/weibo/&lt;search-string&#038;gt</a>;</em></span> shall be parsed instead of going the traditional way using the API call by authenticating via the key.</p>
<p><br />
Sample code snippet to extract the title of the page:</p>
<p><span><code>String q = "Berlin";<br />
//Get the Search Query in "q" here<br />
Document doc = null;<br />
String title = null;<br />
</code><code>try {<br />
doc = Jsoup.connect("http://s.weibo.com/weibo/"+q).get();<br />
title = doc.title();<br />
} catch (IOException e) {<br />
e.printStackTrace();<br />
}</code></span></p>
