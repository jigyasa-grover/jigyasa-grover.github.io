<p>The intended <strong>“</strong><strong>searchQuick” (sQuick)</strong> is an application to enable a user to search a set of books or texts, like an encyclopedia, or some other topical book collection offline built in the open source platform Pharo 4.0.</p>
<p><img src="/assets/images/wp-archive/2015/header-046c16eb.png" alt="header" loading="lazy" /></p>
<hr />
<hr />
<p>The main task achieved was putting up the application up on <a href="https://ci.inria.fr/">Continuous Integration, Inria </a>for automated build. It was indeed a beneficial idea as it helped me keep a check on the builds and work on issues.<br />
Being a newbie, this work was cumbersome initially but with the help of my mentors and the <em>#pharo</em> community, I was able to accomplish it. To assist fellow Pharo-ers, I have compiled all the information regarding <a href="/ci-automated-build-for-your-pharo-application/">CI Automated Build for yout Pharo Application</a> and published the same on my blog-spot. Kindly go through it for a complete understanding 🙂</p>
<p><strong>Other tasks completed as of now include:</strong></p>
<ul>
<li>Putting up the project for automated build on <a href="https://ci.inria.fr/">https://ci.inria.fr/</a></li>
<li>Successful &#8216;stable&#8217; and &#8216;development&#8217; version builds</li>
<li>Accessing resource folder via MCGitHubRepository, Removal of manual download option</li>
<li>By default full screen system window open</li>
<li>Removing redundant code by creating open argument methods</li>
<li>Abolishment of hard-coded font family and font point size</li>
<li>Categorization of methods &amp; classes</li>
<li>GUI Embellishment with background colors, borders etc.</li>
</ul>
<p><strong>Upcoming: </strong></p>
<ul>
<li>Dynamic widget re-sizing</li>
<li>Multi-line search result title</li>
<li>Putting up Help and About sections</li>
<li>Removal of old configurations</li>
</ul>
