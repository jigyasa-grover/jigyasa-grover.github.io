<p><strong>Hi !</strong></p>
<p>I started with Git/GitHub (<a title="GitHub" href="https://github.com/" target="_blank">github.com</a>) a couple of months back without the slightest idea of its vast functionality and capability. I did self-learning of Git using resources available online and was amazed by its powerful concept and design.</p>
<p>In this post I have shared links to various documentations/videos/tutorials which would surely help beginners gain a moderate level of expertise in using Git version control system.</p>
<p><img src="/assets/images/wp-archive/2015/git-logo-bea267af.png" alt="git-logo" loading="lazy" /></p>
<p><strong>OVERVIEW</strong> : Git is a <em>Distributed Version Control System (DVCS)</em> that helps software developers to work together, mirror repositories and maintain a complete history of their work. Git does not rely on the central server and that is why one can perform many operations when one is offline. The user can commit changes, create branches, view logs, and perform other operations when you are offline. Only a network connection is required to publish the changes and take the latest changes.</p>
<p>Lately, Git has become immensely popular, especially among the open source community which has gained hold with the rise of the Internet, and the attendant need for massive retooling of the computing source code.</p>
<p>Do have a look at this <a title="Git Guide" href="http://rogerdudler.github.io/git-guide/" target="_blank">Git Guide</a> which explains using Git step by step in a very systematic manner.<br />
You could also watch this <a title="GitHub Tutorial" href="https://www.youtube.com/watch?v=0fKg7e37bQE" target="_blank">GitHub tutorial video</a>  to have an insight into the functionality and usage of Git.</p>
